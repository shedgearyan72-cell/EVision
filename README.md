# EVision
EVision is a smart parking management system designed to detect available and occupied parking slots using ultrasonic sensors and a microcontroller. The system provides real-time parking slot status, helping drivers quickly find available spaces and reducing parking congestion.

Features
1. Real-time parking slot monitoring
2. Detects occupied and free parking spaces using ultrasonic sensors
3. LCD display for instant slot status updates
4. Low-cost and easy-to-build hardware setup
5. Scalable design for multiple parking slots
6. Suitable for colleges, malls, offices, and residential parking areas
   
Hardware Used
1. Arduino Uno
2. HC-SR04 Ultrasonic Sensors
3. Jumper Wires
4. USB Cable

Applications
1. Smart Parking Systems
2. Shopping Malls
3. Educational Institutions
4. Office Complexes
5. Residential Societies
